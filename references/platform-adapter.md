# 平台适配器参考

先保留 `ArchiveStore`、`clean_article_html`、`validate_archive` 和原子写入逻辑，仅替换以下站点层能力：

1. **访问判定**：用用户已经购买课程后可见的正文或继续学习控件判断，不以固定等待时长代替登录验证。
2. **目录收集**：展开并滚动真实目录，记录稳定文章 ID、URL、顺序、章节和页面稳定显示的已更新讲数。ID 优先于标题。
3. **正文定位**：为正文容器设置明确 selector；在样本中确认不包含目录、评论、推荐或页脚。
4. **文章遍历**：优先按稳定 URL/ID 打开；“下一篇”只可作为目录导航失败时的回退，并用 URL 与正文签名双重判断页面已切换。
5. **图片下载**：在浏览器上下文中带 Referer 下载正文图片，记录失败原因但不得把远程链接留在已交付 Markdown。
6. **增量策略**：新 ID 全抓；最近 N 讲用正文/图片哈希复查；页面减少或暂时消失只报告，绝不删除本地历史。

把 selector、可见文本和噪声正则写成适配器常量或配置，并为每一种内容类型添加最小 HTML/DOM 测试。完成后至少跑一次全量对账和一次无新增幂等测试。
