# 出版阅读版参考

仅在用户要求阅读版时执行本流程，并先调用 `windows-office-files`。Markdown、图片和 manifest 是归档权威源；DOCX 是可编辑权威版本；PDF 不直接修改。

1. 按发布月或用户指定分卷，从 manifest 顺序读取文章与本地图片。
2. 每讲另起页；正文、图片和说明均从本地归档读取。长图按页宽等比缩放，必要时分段，不能裁掉有效内容。
3. 用真实 Microsoft Word 导出 PDF 与 XPS；不能只用 Python 生成 PDF 后宣布验收。
4. 对 DOCX 做 ZIP/`python-docx` 回读，对 PDF/XPS 做签名与页数比对，并渲染 XPS 页面检查空白页、标题孤行、图片裁切、字体替换和页眉页脚。
5. 仅在全部检查通过后用新版本替换正式成果；失败时保留上一版成功交付。
